# Streamlit GUI Applications

## Overview

This repository contains Python-based GUI applications developed using **Streamlit**.

The objective is to explore Streamlit fundamentals and understand how to build interactive web applications using Python without requiring traditional frontend development.

## Project 1: Addition Calculator

A simple interactive addition calculator developed using Streamlit.

### Features

- Accepts two numerical inputs from the user.
- Provides an interactive Addition button.
- Performs addition when the button is clicked.
- Displays the calculated result using Streamlit's success message.

### Technologies Used

- Python
- Streamlit

```text
Streamlit-GUI-Applications/
```

### Installation and Execution

**1. Clone the repository**

```bash
git clone https://github.com/aartiwamane/Streamlit-GUI-Applications.git
```

**2. Navigate to the project directory**

```bash
cd Streamlit-GUI-Applications
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the virtual environment (Windows)**

```bash
venv\Scripts\activate
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Run the Streamlit application**

```bash
streamlit run 3_GUI_Addition_Streamlit.py
```
